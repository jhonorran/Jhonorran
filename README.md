## 👨‍💻 Sobre mim

Olá! Eu sou **Jhonatan Gabriel Nunes**.

Sou estudante de **Análise e Desenvolvimento de Sistemas** e estou construindo minha trajetória como **Desenvolvedor Full Stack**.

Atualmente estou focado em fortalecer minha base de programação, desenvolver projetos próprios e entender cada vez melhor como as diferentes partes de uma aplicação se conectam — do front-end ao back-end, banco de dados, APIs e ferramentas de desenvolvimento.

Gosto de aprender colocando a mão na massa. Por isso, muitos dos meus estudos acabam virando pequenos projetos, aplicações e experimentos que posso colocar em prática.

### 🚀 Atualmente estudando

- ☕ Java
- 🟨 JavaScript
- 🐍 Python
- 🌐 HTML & CSS
- ⚛️ React
- 🔧 Git & GitHub
- 🗄️ Bancos de dados
- 🔌 APIs e desenvolvimento Back-end
- 🐳 Docker

> **Objetivo:** evoluir constantemente como desenvolvedor e transformar conhecimento em projetos reais.
